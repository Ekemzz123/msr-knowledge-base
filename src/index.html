Data Sources

Where MSR researchers get their data from.

SourceData ProvidedDescription
GitHubRepositories, commits, pull requests, issues, starsThe largest platform for hosting open-source projects, widely used to study development activity and collaboration.
Stack OverflowQuestions, answers, tags, user reputationA Q&A site for programmers, useful for studying developer problems, knowledge sharing, and expertise.
JIRAIssue tracking, sprint data, bug reportsA project management tool used by many teams, useful for studying bugs, planning, and agile practices.
App StoresGoogle Play and Apple App Store reviews, ratings, downloadsMobile app marketplaces where user feedback can be analyzed to understand app quality and user needs.
Travis CI / JenkinsBuild logs, test results, deployment dataContinuous integration services that record build and test outcomes, useful for studying CI practices and failures.
Mailing ListsDeveloper discussions, archivesEmail-based discussion archives from open-source communities, useful for studying communication and decision-making.
npm RegistryPackage dependencies, downloads, versionsThe JavaScript package registry, useful for studying software ecosystems and dependency management.
